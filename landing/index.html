APIs were built for humans.
AI agents need a new way to pay.

Agents don't have credit cards. They can't fill out forms or sign contracts. But they can sign transactions. Turnstile bridges that gap — any API becomes agent-accessible with a single endpoint.

How It Works

Three steps. No SDKs. No crypto operations on your end.

01

Register your API

Point us at your origin URL. Set your price per request. We give you a Turnstile endpoint. Zero code changes to your service.

02

Agents pay on-chain

AI agents send USDC on Base to your endpoint. Turnstile verifies the transfer on-chain in real time and proxies the request through.

03

You get paid

Every verified payment is logged in your ledger. We handle the crypto. You receive USD. No wallets, no token management.

For agent builders

Give your agents access to any API behind Turnstile with a simple protocol.

  • GET the endpoint to discover price and wallet
  • Send USDC, get a tx hash
  • POST with X-Payment header to access the API
  • No API keys, no OAuth, no contracts

The Protocol

Two HTTP calls. One on-chain transfer. That's it.

# 1. Discover payment details
GET /v1/gateway/{client_id}
Response:  { wallet, amount, chain_id, usdc_contract }

# 2. Pay USDC on Base (agent does this on-chain)

# 3. Access the API
POST /v1/gateway/{client_id}
X-Payment: 0x{tx_hash}
Body:       { your request payload }
Response:  { proxied response from origin API }
